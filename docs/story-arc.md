# Story arc

Video: 1080x1920, 30fps, 2-4 minutes.

1. **Hook** — the interview question or a provocative result.
2. **Stakes** — why it matters in real work.
3. **Mental Model** — animated diagram explaining the essence.
4. **Live Refactor** — code diff with morph.
5. **Trade-offs** — options, pros and cons.
6. **Takeaway + loop** — summary, with a closing line that leads back into the hook.

Re-hook (pattern interrupt) around **second 45** and **second 100**.

Scene types in the schema: `hook`, `diagram`, `code`, `terminal`, `tradeoff`, `summary`.
