# Cache warming và cold start

- Level: senior
- Ngày đăng: 18/01/2027 lúc 19:30

## Câu hỏi phỏng vấn

Bạn deploy cache cluster mới hoặc failover làm cache trống, database sắp quá tải. Bạn làm ấm cache (cache warming) thế nào và giữ nhất quán dữ liệu khi quy mô lớn?

## Vì sao nhà tuyển dụng hỏi

Kiểm tra bạn lên kế hoạch cho cold cache khi vận hành: warming, ramp-up traffic, nhất quán.
